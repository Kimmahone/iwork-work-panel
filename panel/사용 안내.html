선택하고, 옆에서 바로 누르세요.

문서에는 문서 도구, 계산표에는 셀 도구, 발표에는 슬라이드 도구, Freeform에는 보드 도구가 표시됩니다.

설정 2.1 · 개인 Mac용 로컬 편집 도우미. 유료 개발자 계정이나 별도 AI 요금이 필요하지 않습니다.

처음 쓸 때

  1. 시계 근처 ✦ 편집 → 클릭 패널 보이기 / 숨기기를 누릅니다.
  2. Pages·Numbers·Keynote 문서 또는 Freeform 보드를 엽니다. 패널 상단에 현재 앱 이름과 버전이 표시됩니다.
  3. 글자·셀·이미지·차트를 먼저 선택합니다.
  4. 왼쪽 분류에서 글자(셀) / 표 / 그림 / 차트를 고른 뒤 버튼을 누릅니다. Freeform에서는 글자 / 보드 / 표 / 그림 / 정렬가 표시됩니다.

나란히를 누르면 문서 창과 패널을 옆으로 배치합니다. 다시 누르면 원래 창 크기로 돌아갑니다. 상단 흰색 제목줄은 끌어서 이동할 수 있고, ×는 패널만 숨깁니다.

화면 아래 ‹ / ›는 다음 도구 페이지입니다. 적용 결과는 패널 맨 아래에 표시됩니다. 사용 안내를 누르면 현재 앱의 아래 설명으로 바로 이동합니다.

내 스타일로 바꾸기

프리셋 설정 → 바꿀 프리셋 → 이름·크기·굵기·정렬을 고릅니다. 한 항목씩 바꾸고 저장하면 다음 클릭부터 적용됩니다. Numbers는 글자색·배경색도 바꿀 수 있습니다.

글자 프리셋은 현재 글꼴을 유지합니다. 사진 여러 개의 크기·배치를 적용한 뒤에는 다음 작업 전에 사진들을 다시 선택하세요. 여러 서식을 한 번에 바꾸므로 실행 취소는 ⌘Z를 여러 번 눌러야 할 수 있습니다.

Pages · 문서와 학습지

1. 본문을 선택하고 정리하기

  1. 바꿀 본문을 드래그합니다. 커서만 깜박이는 상태에서는 적용하지 않습니다.
  2. 패널 위의 본문 정리를 누릅니다.
  3. 12pt·보통·왼쪽 정렬·줄 간격 1.3·문단 앞 0pt·뒤 6pt로 맞춰집니다. 문구는 유지됩니다.

제목은 따로 선택하고 글자 → 학습지 제목 또는 문서 제목을 누릅니다. 보고자·표지 제목·참고·출처·붙임·날짜도 글자 탭에 있습니다. ‘표지 제목’은 선택 글자의 서식을 바꾸며, 새 표지를 추가하지 않습니다.

엔터 정리는 선택한 글자에서 연속 빈 줄만 빈 줄 하나로 줄입니다. 한 번에 1,500자까지 선택하세요. 오늘 날짜는 커서 위치에 실제 날짜를 넣습니다.

2. 용지 여백 맞추기

  1. 문서 안을 클릭합니다.
  2. 글자 → 다음 페이지(›) → 용지 여백을 누릅니다.
  3. 문서 설정에서 아래 값을 확인합니다.
머리말위아래꼬리말왼쪽오른쪽
10mm15mm10mm15mm20mm20mm

본문이 있는 일반 문서용입니다. 페이지 레이아웃 문서·맞쪽 페이지에서는 설정을 직접 확인하세요. 여백 적용이 용지 크기를 A4로 바꾸는 것은 아닙니다.

3. 표를 만들고 편집하기

  1. 표 → 표 양식에서 보고서·비교표·일정표를 고릅니다. 직접 크기를 정하려면 새 표 만들기를 누릅니다.
  2. 표에서 바꿀 셀 범위를 드래그합니다. 셀 안에서 입력 중이면 Esc를 먼저 누릅니다.
  3. 보고서 / 비교표 / 기록표로 전체적인 모양을 고릅니다. 선택 범위의 첫 행만 머리글 색으로 강조합니다.
  4. 배경색·전체선·바깥선·정렬·한 줄 표시·행/열 균등 크기를 필요에 맞게 누릅니다.

4. 사진과 차트

사진을 선택하고 그림 → 작은 사진 / 중간 사진 / 넓은 사진을 누르면 비율을 유지해 너비를 240 / 360 / 480pt로 바꿉니다. 480pt는 A4 좌우 여백 20mm에 맞춘 문서용 크기입니다. 사진 배치 방식과 페이지 밖으로 나가는지는 문서에서 확인하세요.

차트 → 비교 / 변화 / 비중 차트는 편집 가능한 기본 차트를 추가합니다. 차트를 선택한 뒤 스타일과 크기를 고르고, 차트의 데이터 편집에서 실제 자료를 넣으세요.

Numbers · 셀과 데이터

1. 셀 범위를 선택하고 정리하기

  1. 표에서 바꿀 셀을 드래그합니다. 수식을 입력 중이면 Esc로 입력을 마친 뒤 범위를 선택합니다.
  2. 셀 정리를 누르면 12pt·세로 가운데·줄바꿈 켜기로 맞춥니다. 숫자는 오른쪽, 문자는 왼쪽으로 정렬합니다.
  3. 셀 → 표 머리글 / 일반 셀 / 숫자 셀 / 강조 셀로 용도를 지정합니다.

합계 셀은 계산 결과를 강조하는 서식입니다. 합계를 새로 계산하지 않습니다. 입력 셀은 입력할 칸을 연한 노랑으로 표시합니다.

금액·백분율은 표시 형식을 바꿉니다. 예를 들어 0.25에 백분율을 적용하면 25%로 보입니다. 값과 수식은 그대로입니다. 텍스트 형식은 상품 코드처럼 문자열을 입력할 빈 칸에 미리 지정하세요. 내용이 있는 셀은 값·수식을 보호하기 위해 변환하지 않습니다.

2. 표 양식과 셀 편집

  1. 표 → 표 양식에서 명단·체크리스트 / 예산·정산 / 평가 기록을 고릅니다.
  2. 새 표의 예시 항목을 실제 자료로 바꿉니다. 체크리스트에는 체크박스, 예산표에는 수량×단가와 합계 수식이 들어 있습니다.
  3. 기존 표는 셀 범위를 선택하고 데이터표 / 머리글 강조 / 입력표를 누릅니다.
  4. 색·테두리·맞춤·줄바꿈을 고릅니다. 다음 페이지(›)에는 내용에 맞춘 행 높이·열 너비가 있습니다.

3. 이미지와 차트

그림 탭에서 사진 너비를 240 / 360 / 720pt로 바꿉니다. 사진 여러 개를 선택하면 같은 높이와 사진 나란히를 사용할 수 있습니다.

차트로 만들 셀 범위를 먼저 선택하고 차트 → 비교 / 변화 / 비중을 고릅니다. 숫자와 분류 이름이 올바르게 연결됐는지 확인한 뒤 스타일·크기를 적용합니다.

4. 출력 여백

Numbers는 Pages와 문서 구조가 다릅니다. 파일 → 프린트에서 용지·방향·내용 크기·여백을 확인하세요. Pages의 여백 버튼은 Numbers 패널에 표시하지 않습니다.

Keynote · 슬라이드와 발표

1. 글상자 전체에 서식 적용

  1. 글상자 테두리를 한 번 눌러 조절점이 보이게 선택합니다.
  2. 글을 편집 중이면 ⌘Return으로 글상자 선택으로 나옵니다.
  3. 글자 → 슬라이드 제목(48pt) / 소제목(32pt) / 본문(24pt) / 핵심 문장(36pt)을 누릅니다.

간지 제목 54pt, 출처·설명 18pt, 큰 숫자 64pt, 핵심 질문 40pt도 있습니다. 일부 글자만 바꾸려면 그 글자만 드래그하세요.

본문 정리는 24pt·보통·왼쪽·줄 간격 1.2·문단 앞 0pt·뒤 10pt로 맞춥니다. 글상자가 작으면 문장이 넘칠 수 있으므로 상자 크기도 확인하세요.

2. 발표용 표

  1. 표 → 표 양식에서 비교표·핵심 지표·3단계 실습을 고릅니다.
  2. 표의 내용과 너비를 슬라이드에 맞게 조절합니다.
  3. 셀 범위를 선택하고 발표표 / 비교 강조 / 활동표를 누릅니다. 기본 글자는 24pt입니다.
  4. 색·선·가로/세로 맞춤을 적용합니다. 표 전체 선택과 셀 범위 선택을 구분하세요.

3. 사진을 가지런하게

그림 탭의 작은 사진은 360pt, 중간 사진은 640pt입니다. 넓은 사진은 슬라이드 너비에서 좌우 60pt씩 뺀 크기입니다. 비율을 유지합니다.

Shift를 누르며 사진 2~4개를 선택하고 사진 나란히를 누르면 같은 높이와 24pt 간격으로 배치합니다. 현재 높이만 맞추려면 같은 높이를 누릅니다.

4. 차트와 슬라이드 크기

차트 → 비교 / 변화 / 비중으로 새 차트를 추가하고 데이터 편집에서 실제 값을 넣습니다. 차트 선택 후 크기와 스타일을 고르세요. 스타일 1~3은 차트 스타일 선택기의 현재 페이지에 있는 첫째·둘째·셋째 서식입니다. 색상은 현재 테마와 스타일 페이지에 따라 달라집니다.

슬라이드 크기는 Keynote의 문서 → 슬라이드 크기에서 설정합니다. Pages용 용지 여백 버튼은 표시하지 않습니다.

Freeform · 버튼 순서대로 따라 하기

보드에서 대상 선택 → 패널에서 분류 선택 → 버튼 클릭 순서로 사용합니다. 패널 상단에 Freeform이 표시되는지 먼저 확인하세요.

패널이 안 보이면 메뉴 막대 ✦ 편집 → 클릭 패널 보이기 / 숨기기를 누릅니다. 버튼이 안 보이면 패널 아래 ›로 다음 도구 페이지를 엽니다.

① 메모·글상자② 도형 연결③ 표 편집④ 사진 편집

① 메모·글상자 만들고 서식 정리하기

  1. 패널 보드 → 스티커 메모 또는 글상자를 누릅니다.
  2. 생성된 메모나 글상자를 더블클릭해 내용을 입력합니다.
  3. 입력을 마친 뒤 Esc → 대상 테두리 클릭으로 전체를 선택합니다.
  4. 패널 글자 → 원하는 프리셋을 누릅니다.

버튼기본 서식추천 용도

기본 서식으로 통일: 메모 또는 글상자 한 개 선택 → 상단 글자 정리. 문구·글꼴·카드 색은 유지하고 18pt·보통·왼쪽 정렬로 맞춥니다.

일부 글자만 바꾸기: 더블클릭 → 바꿀 글자를 드래그 → 프리셋 클릭. 크기·굵기는 선택한 글자에, 정렬은 해당 문단에 적용됩니다. 여러 메모는 한 개씩 적용하세요.

같은 스타일 옮기기: 원본 선택 → 글자 → 스타일 복사 → 대상 선택 → 스타일 붙이기. 추가 조절은 굵게 / 밑줄 / 취소선 / 왼쪽 / 가운데 / 오른쪽 / A− / A+를 사용합니다.

프리셋 설정에서 이름·크기·굵기·정렬을 바꿀 수 있습니다. 크기는 Freeform의 10·12·14·18·24·36·48·64·72·96·144pt 목록을 사용합니다. 직접 바꾼 프리셋은 패널에 표시된 값을 따릅니다.

② 도형을 만들고 연결하기

  1. 보드 → 둥근 카드 / 사각형 / 타원 / 마름모 중 하나를 누릅니다.
  2. 도형을 더블클릭해 글을 넣고, 끌어서 위치를 잡습니다.
  3. 같은 모양이 더 필요하면 도형 선택 → 보드 → 선택 복제를 누릅니다.
  4. Shift를 누른 채 도형 두 개를 클릭해 함께 선택합니다.
  5. 패널 보드 → 연결선을 누릅니다.
  6. 연결 위치를 바꾸려면 선을 선택하고 끝의 파란 점을 원하는 연결 위치로 끕니다.

화살표 선은 방향을 표시할 선을 추가할 때 사용합니다. 추가한 선의 양 끝 위치를 보드에서 조절하세요.

가지런히 배치: 여러 도형 선택 → 정렬 → 위쪽 맞춤. 3개 이상 선택하면 가로 간격 같게 / 세로 간격 같게도 사용할 수 있습니다.

함께 움직이기: 여러 대상 선택 → 정렬 → 그룹. 따로 수정할 때는 그룹 해제. 전체 흐름을 보려면 보드 → 보드 전체 보기를 누릅니다.

Apple 공식 도형 연결 안내

③ 표 만들고 편집하기

  1. 표 → 새 표 추가를 누릅니다.
  2. 셀을 더블클릭해 내용을 입력합니다.
  3. 행·열을 늘릴 때는 기준 셀 선택 → 표 → 아래에 행 / 뒤에 열을 누릅니다.
  4. 테두리는 Esc → 표 전체 선택 → 표 → 전체선 / 바깥선 / 선 없음으로 바꿉니다.
  5. 색상은 테두리·채우기…를 눌러 열린 Freeform 설정에서 고릅니다.
  6. 글자는 표 글자…, 크기는 행·열 크기 설정…에서 조절합니다.

크기와 정렬 통일: 필요한 행·열을 선택 → 행 높이 같게 / 열 너비 같게. 글자는 셀 선택 → 왼쪽 / 가운데 / 오른쪽으로 맞춥니다.

… 버튼은 세부 설정창을 엽니다. 창에서 색·글자·크기를 고르세요. 테두리 버튼이 적용되지 않으면 Esc를 누르고 표 전체를 다시 선택합니다.

④ 사진 넣고 편집하기

  1. 그림 → 파일·이미지 넣기… → 사진 선택으로 넣습니다.
  2. 보드에서 사진을 클릭합니다.
  3. 그림 → 원형 사진 / 둥근 사진으로 모양을 바꿉니다.
  4. 보이는 부분을 조절하려면 사진 자르기를 누르고 사진 위치와 확대 정도를 조절합니다.
  5. 원래 자르기 상태로 돌아가려면 자르기 초기화를 누릅니다.
  6. 사진이 글자를 가리면 맨 뒤로, 강조하려면 그림자를 사용합니다.

여러 사진 정렬: Shift로 사진을 함께 선택 → 정렬 → 위쪽 맞춤 → 가로 간격 같게. 간격 맞추기는 사진 3개 이상을 선택하세요. 다음 편집 전에 필요한 사진을 다시 선택합니다.

복제: 사진 선택 → 그림 → 선택 복제. 크기를 조절할 때는 비율 유지 설정 상태를 확인하세요.

버튼이 회색일 때: 보드에서 작업할 대상을 다시 선택하세요. 결과가 마음에 들지 않으면 상단 되돌리기 또는 ⌘Z를 누릅니다. 여러 서식을 적용했다면 여러 번 눌러야 할 수 있습니다.

배경 제거·장면 등 고급 기능의 모든 결과는 아직 실기 검증하지 않았습니다. 검증 범위 보기. 기존 FreeformBridge 앱을 다시 설치하거나 권한을 재등록할 필요는 없습니다.

버튼이 적용되지 않을 때

  1. 패널 위의 앱 이름이 편집 중인 앱과 같은지 확인합니다.
  2. 적용할 글자·셀·이미지·차트를 먼저 선택합니다. 셀은 입력 커서가 아닌 셀 테두리가 보여야 합니다.
  3. 패널 아래 메시지를 확인합니다. 적용 중일 때는 잠시 기다립니다.
  4. 허용창이 나타나면 Hammerspoon의 앱 제어 권한을 직접 허용합니다. 설정 위치는 macOS 개인정보 보호 및 보안 → 자동화 / 손쉬운 사용입니다.
