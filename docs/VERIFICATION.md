# 검증 범위 · 2026-10-24

이 Mac의 한국어 Pages·Numbers·Keynote Creator Studio 15.4, Freeform 5.0, Hammerspoon 1.1.1에서 실행했습니다. 시험 문서와 별도 시험 보드를 사용했습니다. 기존 사용자 문서는 시험 대상으로 사용하지 않았습니다.

- iWork 세 앱의 기본 단축키 16종씩: 실제 전역 키 입력을 통한 실행 확인.
- iWork 세 앱의 표 편집 24종씩: 선택 정리, 스타일, 채우기, 테두리, 정렬, 줄바꿈, 행·열 크기 및 추가 확인.
- 앱별 새 표 양식 9종과 4행 3열 새 표: 내용, 행·열 수, 글자 크기, 기존 표 보존 재검증. Pages의 새 표를 잘못 식별하던 문제를 수정했습니다.
- Numbers 예산표의 곱셈·합계 수식과 체크리스트 체크박스 확인.
- 글자·셀 프리셋, Keynote 글상자 전체 서식, 사진 크기·정렬·그룹, 차트 생성·스타일·크기 확인.
- Pages 여백: 머리말 10 / 위 15 / 아래 10 / 꼬리말 15 / 왼쪽 20 / 오른쪽 20mm.
- Freeform: 전체 글상자와 부분 선택 프리셋, 메모·도형·연결선·표 삽입, 테두리, 사진 파일 삽입과 마스크, 정렬·그룹·보드 보기 확인.
- Hammerspoon 설정을 다시 불러온 뒤 사용자 프리셋 보존 확인.
- 사용자가 Freeform 안내의 네 가지 바로가기를 직접 눌러 해당 설명으로 이동함을 확인했습니다.

## 남아 있는 범위

다른 Mac·OS·언어·구버전 전반과 모든 문서 배치는 별도 확인이 필요합니다. Freeform 배경 제거·장면·링크·잠금 등은 네이티브 메뉴에 연결했으며, 모든 결과를 실기 검증하지 않았습니다.

Numbers의 텍스트 형식은 입력 전 빈 셀에 적용합니다. 이미 내용이 있는 셀은 값과 수식 보존을 위해 변환을 막습니다. 사진 여러 개를 연속 편집할 때는 다음 작업 전에 다시 선택하세요.

공개 배포용 설치 스크립트는 임시 설정 폴더에서 신규 설치, 재설치, 개인 설정 보존, 제거, 손상된 파일 차단을 검사합니다. 이 검사는 다른 Mac에서의 GUI 설치 실기를 대체하지 않습니다.
